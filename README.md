# 影之刃零地图获取指引

当前交付为 `0.4.0` 核心版：地图简讯、来源位置标记、收集清单与筛选、清单定位。完整任务前置、最早可取章节、自动路线和对白扩展已按要求搁置；实验模块不进入本包，任务及标签条件组的扩展状态查询不启用。

## 当前功能

- 点击或悬浮显示名称、来源章节与附近铃铛；点击后保留，默认简讯不展开长说明。地区章节不等于已核实的最早可取章节。
- 原生障碍需求与进度收在可展开详情中；游戏信息全部来自内部数据，不使用社区攻略。尚未解析的任务前置或获取流程保持未知。
- 收集清单支持汉字、拼音、首字母和原生编号搜索，例如 `ju`、`juxiongfu`、`jxf` 均可查询巨凶斧。
- 水墨配色和原生字体默认启用；用户已确认主题、默认文字和面板位置正常。拖动面板按要求延期。
- 点击原生地图的武装或钥匙障碍，显示所需物品与配置中的获取地区。
- 在来源地区显示临时获取点；切换原生地图时保留目标，点击空白处不会清除指引。
- 原生地图点选只显示指引，保持地区和视野；收集清单点选直接定位来源。只自动打开已由激活铃铛证明解锁的地区，未解锁地区保持当前地图。这两种交互和标记缩放不闪烁已由用户验收。
- 获取详情可读取原生事件奖励、静态掉落配置、关联选项及物品数量条件；配置中含有物品不等于实际获得或必定掉落。
- 收集清单读取原生配置，支持名称搜索、类别、地区、进度筛选及分页。
- 附近铃铛按几何距离选取，仅作位置参考，不代表已确认可走路线或传送解锁。
- 详情保留已有的原生获取说明、障碍所需武装及持有状态。未核实的信息保持未知，不以来源地区章节冒充最早可取章节。
- 所需武装只读取原生障碍需求，持有判断与“本周目获得”统计分开，不推测原生表中缺失的前置。
- 区分本周目物品获取与地点完成；同一武装的多个来源不会重复计算为多个已完成地点。

清单已发现 530 条地图记录，覆盖影之武装、武器、配饰、药品、钥匙、普通道具、记忆之花、黑石、琥珀及三种挑战。记录数不等于唯一物品数或成就完成度。

拼音字典派生自 [mozillazg/pinyin-data v0.15.0](https://github.com/mozillazg/pinyin-data/tree/v0.15.0)，仅用于语言搜索，不含游戏攻略。采用 MIT 许可证，版权与完整许可保留在生成的 `pinyin_map.lua` 中。构建时固定原始数据 SHA256，运行时不联网查询。

## 必需前置

- PC Steam 版游戏。
- PowerShell 7；安装入口不使用 Windows PowerShell 5.1。
- 与本游戏兼容的 UE4SS。已有本机测试基线为 KintaroModding 的 `v3.0.1-1188-gf885e8d2`，Steam Build `26266538`。前置加载器不包含在本包中。

在[UE4SS 构建下载页](https://github.com/KintaroModding/ue4ss/releases/tag/v3.0.1-1188-gf885e8d2)中，选择 `phantombladezero_ue4ss_v3.0.1-1188-gf885e8d2.zip`，不要选择 Source code。将前置包中的 `dwmapi.dll` 与 `ue4ss` 目录放到实际的 `platform/steam/` 下。该页面与游戏专用文件名已于 2026-11-01 核对。

## 安装

1. 退出游戏。
2. 解压完整候选包，保留 `manifest.json`、`payload`、`tools` 和安装入口的相对位置。
3. 运行 `INSTALL.cmd`。安装器读取 Steam 库定位游戏；确实缺少目标写权限时才请求系统提权。
4. 从 Steam 正常启动游戏、进入存档并打开地图。无需额外启动器或覆盖 pak。

手动指定目录或自动执行时，可使用 PowerShell 7：

```powershell
pwsh -NoProfile -File .\install.ps1 -GameRoot 'D:\SteamLibrary\steamapps\common\PBZ' -NoPause
```

上述目录仅为示例，实际目录可从 Steam 的“浏览本地文件”进入。

安装后目录结构：

```text
PBZ/
├─ platform/steam/
│  ├─ PBZ.exe                       游戏原有文件
│  ├─ dwmapi.dll                    UE4SS 前置文件
│  └─ ue4ss/
│     ├─ UE4SS.dll                  UE4SS 前置文件
│     └─ Mods/
│        ├─ mods.txt                仅合并 PBZMapGuide 启用行
│        └─ PBZMapGuide/
│           ├─ Scripts/main.lua     本 Mod 正式入口
│           ├─ Scripts/lib/         本 Mod 自有模块
│           └─ .pbz-map-guide-install.json
└─ ProjectPBZ/Content/Paks/         游戏资源，本入口不改写
```

## 升级、核验和卸载

升级时退出游戏，再运行新包的 `INSTALL.cmd`。安装器校验旧清单和文件哈希，备份后替换，并回收已归属的退役文件；未知或被修改的文件不会直接覆盖。

独立核验：

```powershell
pwsh -NoProfile -File .\install.ps1 -Action Verify -NoPause
```

运行 `UNINSTALL.cmd` 卸载。仅移除清单中哈希匹配的本 Mod 文件和本 Mod 启用行，保留用户设置、其他 Mod、共享加载器及事务备份。若自有脚本已被用户修改，卸载会停止并说明保留原因。

## 已知限制与搁置项

- 本核心版没有自动路线或嵌套对白扩展；独立地图预览已按要求取消，面板拖动按要求搁置。
- 最早获取章节、实际任务前置、获取方式与路线：缺少证据时明确显示尚未核实；地区所属章节不能替代解锁条件。
- 530 行、12 类目录的逐条身份和读取统计已核对，但各类别进度语义与原生计数仍须逐项对照；手柄操作也未完成验收。“当前可获取”不会包含前置未知的记录。
- 游戏补丁后的回归验证；已有安装权限不足时的真实系统提权场景尚未验收。

完整前置、最早可取章节和可靠路线的研究已搁置，不再作为本核心版的交付门槛；现有原生说明不会被表述成完整任务链。当前交付不代表已实现这些扩展功能。

Mod 不修改背包、任务、成就、存档进度或原生手动标记。
